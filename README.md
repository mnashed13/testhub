# TestHub - Test Management Application

A unified test management platform for QA teams. Centers on **Test Runs** scoped to Jira releases, populated with manual test cases and automated tests discovered from GitHub repos.

## Features

- **Dashboard** — Summary cards, recent runs, quick create
- **Projects & Releases** — Sync Jira projects and fix versions
- **Test Cases** — Native CRUD repository with steps, tags, folders, priorities
- **Test Runs** — Execute manual tests, track automated results, view reports
- **GitHub Integration** — Connect repos, discover test files (.feature, .spec, .test)
- **CI Webhook** — Ingest JUnit XML or Cucumber JSON from GitHub Actions
- **Settings** — Configure Jira, GitHub PAT, webhook secret

## Tech Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Prisma ORM + PostgreSQL (Neon)
- Jira Cloud REST API v3
- GitHub REST API (Octokit-style)
- NextAuth.js (credentials provider)

## Setup

1. Clone the repo and install dependencies:
   ```bash
   yarn install
   ```

2. Configure environment variables in `.env`:
   ```
   DATABASE_URL=postgresql://...
   NEXTAUTH_SECRET=<random-secret>
   NEXTAUTH_URL=http://localhost:3000
   AUTH_SECRET=<same-as-nextauth-secret>
   WEBHOOK_SECRET=<auto-generated>
   ADMIN_EMAIL=admin@example.com
   ADMIN_PASSWORD=<strong-password>
   ```

3. Push schema and seed:
   ```bash
   npx prisma db push
   npx prisma db seed
   ```

4. Run dev server:
   ```bash
   yarn dev
   ```

## Configuring Jira

1. Go to **Settings** in the app.
2. Enter your Jira Cloud base URL (e.g., `https://yourorg.atlassian.net`).
3. Enter your Jira email and API token ([create one here](https://id.atlassian.com/manage-profile/security/api-tokens)).
4. Click **Test Connection**, then go to **Projects** and click **Sync from Jira**.

## Configuring GitHub

1. Go to **Settings** in the app.
2. Enter a GitHub Personal Access Token with `repo` scope.
3. Click **Test Connection**.
4. Go to **GitHub Repos**, add your repos, and click **Discover** to scan for test files.

## CI Webhook (GitHub Actions)

1. In **Settings**, copy the Webhook URL and Secret.
2. Add these as GitHub repository secrets: `TESTHUB_URL` and `TESTHUB_WEBHOOK_SECRET`.
3. Add a step to your workflow that POSTs JUnit XML results:

```yaml
- name: Post test results to TestHub
  if: always()
  run: |
    curl -X POST \
      -H "Content-Type: application/xml" \
      -H "x-hub-signature-256: sha256=$(echo -n "$(cat test-results.xml)" | openssl dgst -sha256 -hmac "$WEBHOOK_SECRET" | awk '{print $2}')" \
      -d @test-results.xml \
      $TESTHUB_URL/api/webhooks/ci
  env:
    WEBHOOK_SECRET: ${{ secrets.TESTHUB_WEBHOOK_SECRET }}
    TESTHUB_URL: ${{ secrets.TESTHUB_URL }}
```
